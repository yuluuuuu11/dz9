# ДЗ 9

## Условие задачи (Вариант 4)

Написать программу, выводящую на экран заданную геометрическую фигуру (прямоугольный треугольник), нарисованную с помощью заданного с клавиатуры символа.

---

## 1. Алгоритм и блок-схема

### Алгоритм

1. **Начало.**
2. Запросить у пользователя и **ввести символ**.
3. Запросить у пользователя и **ввести размер R**.
4. Запустить **внешний цикл**, который будет переходить со строки на строку (от первой строки до `R`).
5. Для каждой текущей строки запустить **внутренний цикл**, который печатает символы на экране.
6. После того как текущая строка заполнилась символами, выполнить **перевод строки (`\n`)**, чтобы начать новую строчку спустившись ниже.
7. Повторять шаги 6 и 7, пока не нарисуются все `R` строк.
8. **Конец.**
